# Análise do Sono Animal

Projeto de análise de dados desenvolvido para estudar as relações entre duração do sono, expectativa de vida, tempo de gestação, características físicas e fatores de risco em animais.
Este foi o meu primeiro projeto com o processo de tratamento de dados realizado no **MySQL**, utilizando o Power BI principalmente para criação de medidas, análise e visualização dos resultados.

## Objetivo

Preparar uma base de dados sobre sono animal e construir um dashboard para analisar:

- Média de sono;
- Expectativa de vida média;
- Tempo médio de gestação;
- Índice médio de perigo;
- Sono médio por índice de perigo;
- Sono médio por índice de predação;
- Relação entre peso corporal e peso cerebral;
- Relação entre gestação e expectativa de vida.

## Processo de tratamento

O fluxo do projeto foi: CSV → tabela raw → tabela staging → tratamento no MySQL → VIEW final → Power BI
